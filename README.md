# TriShift — Tricycle Unit Rental System

**IT 14/L — Application Development and Emerging Technologies**

## Project Overview

TriShift is a web-based management system designed to simplify tricycle rental operations. It provides a centralized platform for managing driver assignments, rental collections, vehicle maintenance, and operational records.

The system aims to replace traditional paper-based recording with a more organized, efficient, and reliable digital solution.

## Project Objectives

- Simplify daily tricycle rental operations.
- Improve driver and vehicle assignment management.
- Organize rental payments and financial records.
- Monitor vehicle maintenance and service schedules.
- Improve accountability and record accuracy.
- Reduce manual paperwork and recording errors.

## System Features

- **Dashboard** — Overview of daily operations and important records.
- **Daily Assignments** — Manage driver schedules and vehicle assignments.
- **Rental Collections** — Monitor daily rental payments.
- **Drivers** — Manage regular and substitute driver records.
- **Tricycles** — Organize vehicle information and availability.
- **Maintenance** — Track vehicle repairs and maintenance schedules.
- **Reports** — Generate operational and financial summaries.
- **Import Records** — Import and organize existing records.
- **Activity History** — Monitor system activities and record changes.

## User Roles

### Administrator

Manages daily operations, drivers, vehicles, rental collections, maintenance, and reports.

### Driver

Views personal vehicle assignments and rental payment history.
